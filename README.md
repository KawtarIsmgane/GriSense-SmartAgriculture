ح# GriSense - Smart Agriculture 🌿

Système de détection des maladies végétales par Deep Learning et surveillance IoT en temps réel.

## 🚀 Fonctionnalités
- Diagnostic de 38 classes de maladies (PyTorch CNN).
- Monitoring climatique via Firebase Realtime Database.
- Interface interactive développée avec Streamlit.

## 🛠️ Installation
1. Cloner le projet : `git clone https://github.com/KawtarIsmgane/GriSense.git`
2. Installer les dépendances : `pip install -r requirements.txt`
3. Ajouter votre clé Firebase `serviceAccountKey.json` à la racine.
4. Lancer l'interface : `streamlit run app.py`
